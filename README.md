# Field Manual

A dependency-free, bilingual (EN-US / PT-BR) library of interactive board-game rulebooks. Run `python server.py` and visit `http://127.0.0.1:8765`. Sniper Elite's four original source manuals, the authorized Avalon: The Riven Veil Retail Edition manual, the authorized Pagan: The Fate of Roanoke manual, the authorized Odin's Ravens manual, the authorized Cangaceiros manual, the authorized Coup booklet, the authorized Munchkin core rulesheet, the authorized Pandemic rulebooks (core plus the On the Brink, In the Lab and State of Emergency expansions), the authorized Kelp core rulebook, and the user-authorized Mind MGMT core, SHIFT summary and extra mission details are in `manuals/`; guides link to these same PDFs locally and on GitHub Pages, with anchors to cited pages. You can also open `index.html` directly.

The main game index includes a QR code that opens `https://rbasniak.github.io/boardgames`, so players at the table can open the published guide on their own devices. If the published address changes, update `TABLE_SHARE_URL` in `app.js` and regenerate `assets/share-qr.svg`. `app.js` is only the index and the hash router. Each game lives in its own script: `sniper-elite.js`, `not-enough-mana.js`, `avalon-the-riven-veil.js`, `pagan.js`, `odins-ravens.js`, `western-legends.js`, `lotr-fate-of-the-fellowship.js`, `witcher-path-of-destiny.js`, `cangaceiros.js`, `lotr-duel-for-middle-earth.js`, `coup.js`, `munchkin.js`, `pandemic.js`, `kelp.js`, `mind-mgmt.js`, `galileo-galilei.js`, `heat.js`, `bristol-1350.js`, `love-letter.js`, `sky-team.js`, and `deadwood-1876.js`.

The Sniper Elite guide covers multiplayer rules only. Its map, expansion, Sniper, and optional-rule selections filter the relevant setup steps, components, map rules, turns, examples, and glossary. Optional Special Ops lets players select a rank and allocate exactly that many edges per side; repeated edge types are supported. Match settings and setup checklist progress are saved in browser `localStorage`. Changing the map, expansions, Sniper choice, rank, or optional rules clears checklist progress; **Uncheck all** clears only the checklist and keeps the match configuration, language, and team.

To add another game, use the repository skill at `.github/skills/interactive-rulebook/SKILL.md`. In Copilot CLI, load new skills with `/skills reload`, then ask to create the next game using `/interactive-rulebook`. The skill covers source auditing, repository-local manuals, match options, complete bilingual rules, original iconography, setup checklists, and verification.

Not Enough Mana uses that skill. Its guide is at `#/not-enough-mana` and stores its match separately from Sniper Elite. The Maleficus Praecepta booklet is not in this repository, because redistribution rights were not confirmed. Page links still use `manuals/not-enough-mana_core.pdf#page=N` locally and on GitHub Pages. Individual spell, curse, artifact, and event texts stay on the cards; the booklet does not list them.

Avalon: The Riven Veil uses `#/avalon-the-riven-veil` and stores its 2–4 player match separately. The guide covers the Retail core rules, all four factions, and the four configurable rule modes. Its authorized source manual is `manuals/avalon_core.pdf`, aligned with the route in `server.py` and the references in `avalon-the-riven-veil.js`; the cover is under `assets/covers/`, and individual icon crops from manual pages 24–25 are under `assets/avalon/icons/`. Western Legends also uses that skill. Its guide is at `#/western-legends` and stores its match (`field-manual.western-legends.v1`) and checklist (`field-manual.western-legends.setup.v1`) separately. The manuals are under `manuals/western-legends_*.pdf` and the code is `western-legends.js`. Pandemic also uses that skill. Its guide is at `#/pandemic` and stores its match (`field-manual.pandemic.v1`: language, which of the three expansion boxes you own, player count, difficulty and the eight challenges) separately from its setup checklist (`field-manual.pandemic.setup.v1`), which resets whenever the configuration changes.
